# Project instructions

## Go code

For Go implementation work (writing, changing, debugging, refactoring, or testing `.go` files and Go examples), read and follow [the project Go style skill](.agents/skills/go-style/SKILL.md). Consult its `references/sources.md` when a rule is disputed, version-sensitive, or materially affects an API. Project behavior, compatibility requirements, and existing contracts take priority over style guidance.

# Vidify 项目 PRD

**产品名称**：**Vidify**（CLI 命令：`vidify`）
**全称**：Audio to Video with Subtitles
**版本**：v1.0（MVP）
**文档版本**：2.0
**日期**：2026年4月

---

## 1. 产品概述

### 背景与灵感

很多音频资源（如 EnglishPod、播客、语言课）内容优质，但缺少视频形式，难以在 YouTube、Bilibili、抖音等平台传播。用户需要手动加字幕、制作背景视频，流程繁琐。**Vidify** 旨在通过**本地 Whisper.cpp + FFmpeg** 实现全自动化处理，全部在本地运行，保护隐私且无需联网。

### 核心价值主张

- **极简操作**：拖拽音频 → 简单配置 → 一键生成带字幕 MP4（GUI）
- **CLI 一行命令**：`vidify -i podcast.mp3 -m medium`
- **完全本地**：不上传任何数据，隐私安全
- **高质量字幕**：基于 Whisper.cpp，支持多语言、精准时间戳
- **开发者友好**：先提供强大 CLI，后续提供美观易用的桌面 GUI

### 目标用户

- 内容创作者（播客主、YouTuber、Bilibili UP主）
- 语言学习者 / 老师（将音频课转为视频课）
- 独立开发者 / 音频爱好者
- 非技术用户（通过 GUI）

## 3. 功能需求

### 3.1 核心功能（MVP）

#### Phase 1: CLI 工具（优先实现）

- 支持音频格式：MP3、WAV、M4A、OGG、FLAC
- 支持**单文件**和**文件夹批量**处理
- Whisper.cpp 生成 SRT 字幕
  - 模型选择：tiny / base / small / medium / large（v3）
  - 语言：自动检测 或 手动指定（English / 中文 / Japanese 等）
  - 支持翻译模式（可选将非中文转为中文）
- FFmpeg 合成视频
  - 支持**硬编码字幕**（burn-in，默认）
  - 支持背景图片循环作为视频轨道（用户提供图片 或 使用内置默认图片）
- 输出 MP4 文件（支持自定义输出路径和文件名）
- **CLI 指令设计**：

  ```bash
  # 核心指令（MVP 必须）
  vidify -i input.mp3                  # 最简用法
  vidify -i input.mp3 -m medium -o ./output

  # 常用参数（Phase 1 完成）
  -m, --model       模型（默认 medium）
  -l, --language    语言（默认 auto）
  --translate       是否翻译为中文
  --bg-image        背景图片路径（默认内置）

  # 高级参数（后续迭代再添加）
  --resolution      分辨率（720p/1080p）
  --hardcode        是否硬编码字幕（默认 true）
  ```

#### Phase 2: 桌面 GUI（Wails）

- 图形化界面（Wails v2 + Svelte）
- 支持拖拽文件
- 实时进度显示 + 日志面板
- 字幕样式简单自定义（颜色、字号、位置）
- 生成后视频预览
- 配置保存与加载

### 3.2 非核心功能（后续版本）

- 软字幕（embedded subtitle）支持
- 高级字幕样式编辑（字体、阴影、背景框）
- 字幕翻译（集成本地 LLM）
- 自动生成视频封面
- 支持视频作为背景轨道
- 一键发布到 YouTube/Bilibili（未来）

## 5. 功能规格与流程

### 主要处理流程

1. 用户提供音频文件路径
2. Whisper.cpp 进行语音转文字，生成 SRT 字幕
3. FFmpeg 使用背景图片 + 音频 + 字幕生成最终 MP4

## 7. 技术约束与依赖

- **语言**：Go 1.26
- **核心工具**：
  - **Whisper.cpp**：通过 `os/exec` 调用官方预编译二进制（MVP 最简单可靠方式，后续可升级为 cgo binding）
  - **FFmpeg**：通过 `os/exec` 调用（用户需安装或打包进安装包）
- **GUI 框架**：Wails v2 + Svelte
- **架构原则**：高内聚、低耦合、分层设计（Domain / UseCase / Infrastructure）
- **项目结构**：`/cmd`（cli / gui）+ `/internal` 结构，保证 CLI 与 GUI 代码高度复用

> 详细架构图请参阅 [系统架构图](architecture.md)

## 9. 风险与假设

| 风险                              | 缓解策略                               |
| --------------------------------- | -------------------------------------- |
| Whisper.cpp 二进制跨平台兼容性    | 为每个平台提供预编译二进制             |
| FFmpeg 在用户机器上的安装路径问题 | 启动时检测路径，提供安装引导           |
| 大模型在低配机器的内存占用        | 默认使用 medium 模型，提供模型切换建议 |
